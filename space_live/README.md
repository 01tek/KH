# KH-1 live

Upload a book (or use three public-domain novels, 1.3M tokens), plant facts anywhere, read it into KH-1's fixed 1.9 MB memory on a
ZeroGPU slice, then ask. A memory-off switch shows the same frozen model without it.

- Paper, code and every evaluation log: https://github.com/01tek/KH
- Base model: LiquidAI/LFM2-1.2B (LFM Open License v1.0). Not affiliated with Liquid AI.
- Books: Project Gutenberg (public domain in the US).
